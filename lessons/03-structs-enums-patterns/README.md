# Lesson 03: Structs, Enums, and Pattern Matching

## Goal

Move from loose values to stronger modeling. Rust becomes much more useful when
you stop thinking only in primitive types and start designing data structures.

## Why this matters for your project

Buttons, LEDs, Wi-Fi state, and screen commands all have state. Structs and
enums let you model that state clearly instead of scattering booleans and magic
numbers everywhere.

## Focus topics

- `struct`
- `enum`
- `impl`
- `match`
- `Option` and `Result` as real enums
