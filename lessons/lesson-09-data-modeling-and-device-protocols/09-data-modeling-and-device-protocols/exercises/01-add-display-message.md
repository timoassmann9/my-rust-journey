# Exercise 01: Add Display Message

## Objective

Practice extending a protocol without breaking its internal consistency.

## Task

Add a variant for updating display text, then update the encoder.

Requirements:

- include the text in the encoded output
- choose a simple human-readable format
- keep the naming and encoding style consistent with the existing messages

## Why this exercise exists

Protocol changes are common. The goal is to make them deliberate instead of
ad-hoc.
